## 현재 앱 내 테스트 업데이트

기존 20009 앱에서는 **설정 → 업데이트 확인**으로 20015 호환 패치를 설치한 뒤, 앱을 다시 열어 같은 버튼으로 **30018 경영 기능판**을 설치하세요. 별도 파일 업로드나 명령 실행은 필요 없습니다.

두 APK는 기존 패키지·고정 서명키를 유지합니다. 빌드·서명·무결성 검사는 통과했으며, 사용자 승인으로 공개한 **실기기 미검증 DEBUG 테스트판**입니다. 갤럭시 설치·재실행·저장 데이터 유지 성공을 주장하지 않습니다.

30018에는 영업 시간·손님 대기열·직원·시설·재고 발주·용사 원정·일일 목표가 포함됩니다. 기존 저장은 원본 백업 후 변환합니다.
